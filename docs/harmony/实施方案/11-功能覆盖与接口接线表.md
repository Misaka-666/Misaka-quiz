## 2. M5：建议按三个批次实施

### 批次 A：作用域、复习与操作

在 QuizRepository 中补齐 wrongBookEntriesForCurrentScope、currentWrongBookScopeLabel，统一接收/读取 current_bank、group、bank、all_banks 设置。

isWrongEntryDueForSmartReview、reviewDueWrongEntries、todayWrongBookSmartReviewEntries、todayWrongBookSmartReviewSummary 共享到期谓词；统计与列表必须来自相同集合，不能分别实现筛选。

openWrongQuestion、removeWrongQuestion、markWrongQuestionMastered、clearWrongBook、clearWrongBookForCurrentScope 统一处理身份、状态与持久化结果。清空文案显示实际作用域和数量。

### 批次 B：复用会话入口与记录

- startWrongBookPractice(entries, includeMastered, label)：将错题转换为带来源的 PracticeQuestionSource，复用核心 start。
- startTodayWrongBookReview：先取得到期集合，再进入同一练习入口。
- startFavoritePractice：保留收藏来源，不能全部绑定当前活动库。
- findStudyRecord/deleteStudyRecord：按记录 ID 定位，删除失败不假装成功。
- 记录来源至少可区分普通练习、考试、错题练习、今日复习、收藏练习；成绩页和记录详情对同一记录显示一致。

### 批次 C：搜索与 UI

QuestionSearch.ts → QuestionSearchPage → 带 bankId/questionId 的定位参数 → BankDetailPage 预览。WrongBookPage、FavoritePage、RecordsPage、RecordDetailPage 注册路由后，再替换首页四个占位入口。最后补错题偏好和选项编辑。

## 3. M6：协议接口与平台操作

| 拟迁移入口 | 职责 | 不能承担的隐式副作用 |
| --- | --- | --- |
| buildBackupJson | 快照序列化与 registerAsset 收集 | 不直接删除或移动原资产 |
| exportBanksBackupJson | 过滤选定库及约定关联数据 | 不顺便修改 activeBankId |
| buildBackupZip | 临时目录、backup.json、引用图片、压缩 | 不把整个 filesDir 打包 |
| importBackupBytes | 内容初筛并分派 | 不凭扩展名直接提交 |
| importBackupZip | 安全提取、根文件校验、临时资产解析 | 不覆盖正式状态 |
| importBackupJsonInternal | merge/replace 候选状态构造 | 不先清空旧数据再解析 |
| remapBankAssets | 重映射实际引用，包括关联快照 | 不遗留设备绝对路径 |
| convertEmbeddedDataImages/parseDataImageUri | 校验并限额解码图片 | 不允许任意文件协议 |

兼容识别清单：isWebBackupJson、parseStandaloneJsonPreview、parseStandaloneJsonBanks、looksLikeBankArray、parseStandaloneQuestionArrayBank、parseStandaloneBankJsonObject。优先复用 parseWebQuestionBank，避免多个识别分支重复解析并给出不同答案。

预览模型至少包含库名、题数、图片数、冲突数量、可用策略及警告；最终报告包含新增/合并/跳过/失败数量。DocumentViewPicker 保存以实际返回 URI 和平台文件能力写入，不能把 URI 当普通桌面路径拼接。

## 4. M7：偏好与页面迁移顺序

1. 颜色 token 与主题响应，然后验证已有页面。
2. 壳导航自适应与 tabletSideNavigationEnabled，保留当前 Tab。
3. 外观/刷题/错题/数据管理/关于分级设置，保留已有键名和默认行为。
4. rememberPracticeSettings、rememberExamSettings、practiceNextRequiresResult 接入实际会话条件，不只显示开关。
5. 图片放大、图标、hero 素材、startupSplashEnabled；公式增强记录为可选差异。

主题三态等超出 Android 原字段表达能力的设置按 05 文档明确映射，不悄悄改变旧布尔值语义。

## 5. M8：功能开关与结果模型

M8a 先完成客户端/配置/单题分析/FreeAsk；M8b 再接核对、补解析和题库分析。配置清单包含 provider、baseUrl、Key、modelName、原清单七个功能开关、maxQuestions、timeout、refactorMaxChars；七个开关的实际键从 Android 设置定义逐项映射，不根据名字猜测或漏掉未展示项。

AiSingleQuestionAnalysis 的判定、知识点、建议、置信度等字段按实际模型校验；缺失或格式错误时显示原始结果与错误，不用默认值制造可信结论。缓存随题关联，但必须满足指纹失效规则。

单题正文与可选推理字段分开展示；批处理状态按题库隔离。知识点聚合与文本导出仍属于 M8b 范围，不能仅完成流式面板便宣称完成题库分析。
