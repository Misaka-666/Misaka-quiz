# M8a：AI 客户端、配置与单题功能

文档版本：1.0 · M8 第一批交付 · [返回索引](README.md)

## 1. 基准和技术边界

阅读 Android `ai/MisakaAiClient.kt`、`ai/AiPrompts.kt` 及所有调用者，先列出请求、流式事件、结果模型、错误与取消行为。复用鸿蒙 `spike/HttpSpike.ets` 的已验证路径：`http.createHttp()`、`requestInStream()`、`on('dataReceive')`。

原清单中的 `usingStream` 不作为实现依据。具体超时、销毁、回调注销等 API 以本机 SDK 类型定义和实测为准；本文不宣称所有 OpenAI 兼容服务行为一致。

## 2. 实施顺序

1. 迁移 AiPrompts 到兼容 `.ts`，保持提示词行为，不顺便重写任务目标。
2. 实现纯逻辑 SSE 增量解析器与最小自检。
3. 在 MisakaAiClient.ets 适配平台网络、状态码、取消、资源清理。
4. 接入配置与连通性测试，使用本地 SSE server 覆盖异常。
5. 接 Repository 持有的单题请求状态，再接练习页面板与缓存。
6. 接 FreeAsk 对话面板，最后用用户配置的真实端点验证。

不新建通用网络框架。可复用的解码逻辑保持纯函数，其余按当前客户端最小实现。

## 3. SSE 数据处理

字节块 → 保留跨块状态的 UTF-8 解码 → 行缓冲 → 空行分隔事件 → 合并 data 行 → JSON 增量 → 正文/可选推理字段/usage/终止事件。

- 一个回调可能包含半个字符、半行、多行或多个事件，不能逐块直接 JSON.parse。
- 兼容 LF/CRLF、注释/心跳、空 data、多个 data 行及尾部残留。
- `[DONE]` 与网络正常结束分别处理；未完整结束显示中断，不把半份结构化结果自动写回。
- reasoning_content 是可选服务字段，缺失时隐藏相应展示；不将其存在作为协议必需条件。
- 记录 HTTP 非成功状态的安全摘要，区分鉴权、限流、服务错误、网络中断。
- “超时 0”只作为待验证策略：区分连接超时、首数据等待与流空闲超时；始终可主动取消。

## 4. 任务生命周期与隔离

建议最小状态：idle、connecting、streaming、completed、failed、cancelled。任务携带 requestId、bankId、questionId 和题目内容指纹。

- 请求由 Repository 或现有稳定持有者管理；页面只订阅展示，返回页面不等于取消请求。
- 显式停止会取消请求；终止后拒绝该 requestId 的迟到数据。
- 新请求替换旧请求时，旧回调不能覆盖新面板。
- 题目编辑、题库删除、备份 replace 后，写入前检查身份和指纹；不匹配则保存为待查看结果或丢弃写回并说明原因。
- 完成、失败、取消均注销监听并释放客户端；页面解绑不清空任务结果。
- 进程终止后的继续执行不作为“页面生命周期解耦”的保证；重启可保留已完成缓存，未完成任务标记中断并允许重试。

## 5. 配置与密钥

保留 aiProvider、aiApiBaseUrl、aiModelName 和功能开关的兼容映射；数值设置校验范围。URL 解析后仅接受明确支持的协议，不自动改写用户端点路径导致重复 `/chat/completions`。

aiApiKey 的逻辑字段可对齐 Android，但物理存储不直接等同于普通 preferences。先核对本机安全存储能力，采用合适的平台凭据保护；Key 不进备份、日志、截图或错误报告。尚未实现安全持久化时，可明确仅会话内使用，不能静默降级。

连通性测试说明将发起真实请求，显示首段有效内容延迟及结果；不把网络连接成功等同模型调用成功。发送题目上下文的范围在设置或面板中说明。

## 6. 单题分析与 FreeAsk

- 单题分析：读取当前题快照 → 创建任务 → 流式展示 → 校验最终结构 → 缓存。
- 缓存键包括题库/题目身份、内容指纹、模型/端点标识、提示词版本；不包括 Key。
- 题干、选项、答案、解析、提示词或模型变化后缓存失效；重试不叠加旧正文。
- JSON 容错可剥离围栏等外包装；截断或类型错误不能凭空补成可信答案，保留原文并报告解析失败。
- FreeAsk 包含明确当前题上下文，切题后不把旧对话误关联新题；控制历史发送长度并提供清空。
- AI 结论不自动修改本地标准答案，修改进入 M8b 的确认应用流程。

## 7. 自检与出口

拟新增 ai-stream.mjs：逐字节分块、中文跨块、多个事件同块、CRLF、心跳、多 data 行、DONE、半截 JSON、缺推理字段、取消后迟到事件。

设备测试：返回再进入、旋转折叠、切后台、断网、鉴权失败、限流、停止再启动、改题后旧结果返回。真实端点分别记录服务、模型、日期和覆盖能力，不以一个服务代表全部兼容性。
