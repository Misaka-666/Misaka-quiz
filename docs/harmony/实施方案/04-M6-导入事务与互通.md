# M6 下篇：导入事务与三端互通

文档版本：1.0 · 目标：0.7.0-harmony · [返回索引](README.md)

## 1. 支持格式与识别

根据内容识别 ZIP、完整备份 JSON、web_backup、题库数组、单题库对象、独立题目数组。扩展现有 parseWebQuestionBank；文件名后缀和 PK 魔数只是初筛，仍需校验实际内容。

类型判断按最明确结构到宽松结构进行，避免完整备份被误判为普通题库。未知格式或未来不兼容版本给出明确错误，不能吞掉字段后当成功。

## 2. 导入流程

选择文件 → 限额检查 → 隔离解析/解压 → 校验根 JSON → 归一模型 → 解析资产 → 冲突预览 → 用户选择 merge/replace → 生成候选状态 → 提交 → 结果报告 → 清理。

预览前后不可改变现有正式状态。替换须明确展示将移除的本地内容；取消预览后不产生正式题库或资产。

## 3. 外部输入边界

- 解压前核对本机 zlib 是否支持安全枚举、路径限制和容量控制。若不能在落盘前阻止路径逃逸，不可直接接收任意 ZIP；先解决安全提取能力，不能只在解压后检查。
- 拒绝绝对路径、盘符、父目录穿越及可逃逸链接；校验规范化后目标始终处于本次临时目录。
- 对输入文件、展开总字节、单资产字节、文件数、JSON 层级/题量、data URI 解码量设置明确上限；具体数值经代表性备份测量后记录。
- MIME、扩展名、实际图片内容交叉校验；data URI 只接受本项目支持的图片类型，不接受任意协议或文件路径。
- JSON 校验 ID、类型、数组、答案结构与引用，不用类型断言代替输入验证。

## 4. 冲突规则实现表

| 场景 | 实施要求 |
| --- | --- |
| 相同 bankId、相同题目 | 对照 Android 去重/覆盖规则，重复导入不得意外翻倍 |
| 相同 bankId、不同内容 | 预览冲突；明确保留、覆盖或追加策略 |
| 同名但不同 bankId | 不仅凭名字静默覆盖；按已确认兼容规则处理 |
| 不同库同 questionId | 保留来源身份，错题/收藏不能串库 |
| ID 重映射 | 同步重映射活动库、关联条目、进度键与可映射记录字段 |
| 选择题库导入 | 不改动未包含题库及其关联数据 |
| replace | 明确替换集合与设置范围，不能留一半旧关联数据 |

先将 Android merge/replace 行为写成输入输出例子，再移植；如果基准行为存在数据风险，记录差异并采用保护数据的明确方案，不机械复制缺陷。

## 5. 最小可恢复提交方案

1. 在内存中构造候选状态，旧状态继续可用。
2. 将新资产放入正式目录中不会与旧文件冲突的新名字；此时尚未修改任何旧引用。
3. 所有资产落盘和引用校验成功后，原子写入候选 state.json；失败则保留旧内存/旧状态并清理本次新资产。
4. 状态提交成功后切换内存数据；晚到的旧会话/AI 回调不能继续写入已替换对象。
5. 清理旧资产在提交后执行，且必须检查题库、错题、收藏和记录全部引用。清理失败最多遗留孤立文件，不能影响已提交数据。
6. 若同时更新 preferences，明确状态文件与 preferences 不是同一事务；用可恢复标记/备份完成恢复，或分离为可重试设置步骤并向用户报告部分完成。
7. 重启检查中断痕迹：提交前中断保留旧数据，提交后中断保留新数据。不要仅凭临时文件存在就覆盖正式状态。

采用上述具体流程即可，不为这一需求引入通用事务框架。

## 6. 双向验收矩阵

| 来源 | 目标 | 必查内容 |
| --- | --- | --- |
| 鸿蒙 ZIP | Android | 题、图片、错题/收藏/记录等协议支持字段 |
| 鸿蒙 ZIP | Web | Web 实际支持字段、图片、差异说明 |
| Android 真实 ZIP | 鸿蒙 | 全量与选择范围、进度、资产重映射 |
| Web 真实 web_backup | 鸿蒙 | 多库结构、data URI、兼容字段 |
| 鸿蒙 ZIP | 鸿蒙 | merge 重复导入、replace、导出再导入语义一致 |

C1 单题库 JSON 仅作为格式样例，不能替代完整 Web 备份。每条矩阵记录源/目标版本、文件 SHA256、导入前后统计、已接受差异。

## 7. 故障验收与出口

- [ ] 非法 ZIP、缺 backup.json、非法 JSON、未来版本、路径逃逸、超限压缩内容均拒绝且不损坏原数据。
- [ ] 图片缺失/损坏给出报告，完整恢复不可悄悄略过。
- [ ] 在资产复制、状态写入、提交后清理阶段模拟失败或终止，重启仍可用。
- [ ] 协议自检、原有自检、构建与设备矩阵全通过。
- [ ] 文档写清全量备份范围与跨端不支持字段，完成 M6 版本收尾。
