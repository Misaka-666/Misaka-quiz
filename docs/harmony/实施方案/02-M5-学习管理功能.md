# M5：错题、收藏、记录与搜索

文档版本：1.0 · 目标：0.6.0-harmony · [返回索引](README.md)

## 1. 基准与复用

Android 基准目录：`apps/android/app/src/native/java/com/yiqiu/misakaquiz/`。

核对 `state/QuizRepository.kt`、`state/QuestionSearch.kt`、`ui/screens/` 下 WrongBookScreen、FavoriteScreen、RecordsScreen、RecordDetailScreen、QuestionSearchScreen。按函数名定位，避免依赖原清单的固定行号。

鸿蒙继续复用 PracticeSessionCore 的 items 注入、WrongBookOps 排期、Models 序列化。新增 Repository 薄入口，不在各页面重写判分与复习逻辑。

## 2. 先确定数据语义

按 [数据规则](09-数据一致性与异常恢复.md) 明确删除、快照、身份与编辑策略。重点核对 Android v1.3.4 的指定题库 BANK 分支及收藏分组筛选，不能只补错题作用域而漏掉收藏已有行为。

“未掌握/复习中/已掌握”是状态；“今日到期”是时间筛选，两者可重叠。到期计算使用注入时间；已掌握不自动表示永不复习。

## 3. 实施顺序

### 3.1 仓库查询与操作

1. 补齐 current_bank/group/bank/all_banks 作用域及标签，统一供计数、列表、清空、练习入口使用。
2. 对不存在的题库或分组，返回明确空态，不静默扩大为全库。
3. 实现到期筛选与统计；手动掌握/取消时同步 streak、排期等字段，具体值以基准函数为准。
4. 实现单题打开、删除错题、作用域清空、今日复习、错题练习、收藏练习。
5. start 入口保留 bankId 与 questionId，空集合不启动；是否包含掌握题由参数和偏好确定。
6. 实现 findStudyRecord/deleteStudyRecord；列表按时间排序，详情读取历史快照。

### 3.2 搜索纯逻辑

1. 移植 QuestionSearch 到 `.ts`，先对齐 Android 的关键词归一、匹配字段、题型过滤、排序语义。
2. 结果携带 bankId/questionId，不依赖数组位置。
3. 输入更新触发查询；测出明显卡顿再加防抖或优化，不先引入索引库。
4. 查询结果点击前重新解析身份，题目已删除时提示并刷新结果。
5. 给 BankDetailPage 增加明确的定位参数或既有状态入口，确保路由打开后能展示目标题的预览。

### 3.3 页面接线

| 页面 | 必须行为 |
| --- | --- |
| WrongBookPage | 作用域选择、状态/到期筛选、统计、单题打开、掌握操作、删除、清空、练习 |
| FavoritePage | 按库分组、Android 已有分组筛选、移除、收藏练习 |
| RecordsPage | 来源徽章、正确率/耗时/分数、删除、空态 |
| RecordDetailPage | 当时题目/答案/解析、用户答案、逐题结果；缺失图片占位 |
| QuestionSearchPage | 关键词、当前库/跨库、题型筛选、结果定位 |

为新增路由更新 `main_pages.json`；首页替换占位 toast 并增加今日复习卡。错题默认作用域、智能复习偏好接入 AppSettings。

### 3.4 快速编辑补齐

复用 M4 编辑入口，增加选项文本与新增选项。变更选项时校验 key 唯一、答案指向有效选项、多空答案结构有效；变更后清除当前题旧判分与相关 AI 缓存。是否支持删除选项以 Android 基准为准，不额外扩大范围。
