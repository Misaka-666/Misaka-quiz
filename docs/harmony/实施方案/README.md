## 文档使用方式

1. 先读 00、09、10，再进入当前里程碑。
2. 每次实施前核对当前源码；路径、版本和测试结果可能已变化。
3. 文中的“拟新增”“建议”“待验证”不是已存在接口或已完成能力。
4. 完成后将真实结果写入 [移植进度](../移植进度.md)，不要仅勾选计划代替验收证据。
5. 同一里程碑内按小批次实现与自检，满足出口条件后再更新应用版本。
