# M7：阔折叠适配与体验完善

文档版本：1.0 · 目标：0.8.0-harmony · [返回索引](README.md)

## 1. 范围与优先级

M4 已负责动态布局正确性；M7 完成主题、宽屏导航、设置组织、图片查看与可访问性。先保证可读可操作，再添加开屏和素材。复用 QuizWidgets/MisakaColors 与 Android 现有资源，不新增 UI 框架。

## 2. 主题方案

1. 搜索全页硬编码颜色，分类为背景、容器、正文、弱文字、边框、选中、正确、错误、禁用。
2. 将 MisakaColors 接到现有可响应状态或资源色机制；避免仅替换常量但页面不刷新。
3. UI 使用跟随系统/浅色/深色三态。Android 旧 darkThemeEnabled 若为布尔值，不能直接用一个布尔表达三态；保留兼容映射并明确缺省值，鸿蒙独有偏好单独存储。
4. 系统主题变化或手动切换不重建会话，不清空答案、滚动位置和弹层状态。
5. 正误不能只靠红绿：增加文字或符号；图片背景、输入框、sheet、成绩页均检查暗色对比。

## 3. 宽屏导航与折叠

1. Index 根据实际容器宽度决定底部 Tab 或侧导航；840vp 是候选导航断点，按设备测量复核。
2. 题目双栏断点与壳导航断点独立；不能以 fold open 一律强制宽屏布局。
3. 同一选中 Tab 与页面状态由稳定状态持有，布局变化仅改变导航表现。
4. 平台尺寸监听只注册一次，离开时解除；避免反复折叠后重复回调。
5. 检查安全区、系统手势区域、软键盘、分屏可用宽度，不把模拟器物理分辨率当 vp。
6. 保留 tabletSideNavigationEnabled 对应偏好；关闭后行为与设置说明一致。

## 4. 设置页迁移

| 设置组 | 内容 | 接线要求 |
| --- | --- | --- |
| 外观 | 主题、题干/选项字号、紧凑选项 | 当前页即时刷新，重启保持 |
| 刷题 | 记住练习/考试设置、滑动、自动下一题、下一题需结果、快速编辑、斩题 | 复用 AppSettings，禁用状态说明清楚 |
| 错题 | 智能复习、默认作用域 | 与 M5 页面使用同一查询逻辑 |
| 数据管理 | M6 备份导入导出、空间占用、清空 | 清空二次确认，取消无副作用 |
| 关于 | 实际版本、仓库地址、移植差异 | 版本从应用信息或统一来源读取 |

remember 设置关闭后，区分“本次会话临时配置”与“保存的下次默认值”；不能一边标记不记住，一边把每次操作写回偏好。

清空本地数据时先停止会话和 AI 写入，再按定义范围清除题库、关联数据与资产；是否清除 Key 和外观偏好在确认文案中明确。

## 5. 图片、富文本与素材

- 点击题图打开大图预览，长宽比不变，可关闭；缺图与解码失败显示占位，不阻塞答题。
- 检查单题多图、超长图、超大图；预览释放资源，反复开关不持续涨内存。
- 公式首版允许纯文本，保留解析层已有转换；分数/根号排版增强为后置项，记录可见差异。
- 应用图标与首页素材优先复用仓库资源，核对格式、路径及使用许可；缺失时记录，不用占位冒充最终图标。
- 开屏为可跳过的轻量展示，目标两秒内；不人为延迟已经就绪的主页面，关闭偏好后不显示。
