## 移植策略要点

1. **以 Android native 版为唯一移植基准**（不是 Web 版）——解析器回归测试绑定 Android 实现。
2. **解析器源码用 ArkTS 兼容的 TS 子集编写**（`entry/src/main/ets/importer/**/*.ts`），同一份文件：
   - 被 hvigor 编译进 HAP（.ets 通过相对路径 import）；
   - 被 Node 直接运行做回归测试（Node 24 原生 type stripping，无需 tsc）。
3. **持久化映射**（与 Android 的 SharedPreferences 大 JSON 不同）：
   - 题库/错题/收藏/记录 → `filesDir/misaka/state.json`（临时文件 + rename 原子写），规避 preferences 单值容量限制；
   - 轻量设置 → `@ohos.data.preferences`；
   - 图片 → `filesDir/question_assets/`（沿用 Android 同名目录，保 ZIP 备份互通）。
4. **AI 后置**：核心闭环（导入/练习/考试/错题/收藏/记录/备份）优先，AI 全家桶在 M8。
5. **阔折叠适配为 UI 主线**（用户要求）：所有页面按断点（sm/md/lg）自适应，展开态（1320×2120 内屏）优先设计宽屏侧边导航与双栏布局，跟随 Android 平板侧边导航模式；折叠/半开态回落单栏。折叠态切换需监听并保持页面状态。
6. 每个里程碑合并即 bump `AppScope/app.json5` 版本号 + CHANGELOG.md「HarmonyOS 版」段落 + 更新本文。

踩坑备忘（M2 新增）：

- **Node ESM 不解析无扩展名相对导入**，而 ArkTS 要求无扩展名 → 新增解析钩子 `test/harmony-parser-regression/hooks.mjs`（回落补 `.ts`），经 `ts-node.mjs` 注册；所有测试统一 `node --import ./test/harmony-parser-regression/ts-node.mjs xxx`。
- **Kotlin 原始字符串正则里的 `/` 必须转义为 `\/`**：CodeLikeTextGuard 的 `ASSIGNMENT_REGEX` 曾带未转义 `/=` 导致正则字面量提前截断（Node TS 解析报 Invalid assignment target，ArkTS 同样无法编译）——移植时逐条检查正则内的斜杠。
- **ArkTS 不接受混合元组数组**（`[string[], string]`）→ QuestionTypeLabelParser 用 `AliasGroup`/`AliasEntry` 显式类。
- **Kotlin `String.replace(字面量)` 是全量替换** → JS 需 `split/join`；`maxWithOrNull`/`maxByOrNull` 平局取先者，用严格 `>` 循环实现。
- **解析器生成临时唯一 id**（`q-N`/`xq-N`，对应 Android Question 默认 UUID）：FullPaperFallbackStrategy 依赖 id 定位题段替换；M3 入库时可重新赋值。
- 惯用映射：`lineSequence()`→`split('\n')`（上游 normalizer 已归一 CR）；`IntRange`→`number[][]` 闭区间；`groupValues[i]`→`g(match,i)` 助手；`toIntOrNull()`→正则守卫 + parseInt；`.matches()`→锚定 `test()`。

### 本机模拟器工具坑（重要备忘）

1. `Emulator.exe -imageList -downloaded true` 在本机管道环境下经常返回空 → `devecocli emulator create` 的 osVersion 预校验失败（phone 也一样）。
2. 中断 `image download`（交互 y/N 被 EOF）会打掉镜像安装登记 → 启动报「image cannot be found」；修复：原生 `Emulator.exe -install -deviceType phone -osVersion "HarmonyOS 7.0.0(26.0.0)" -force`（会重新下载 2G）。
3. **widefold 实例为手工登记**（devecocli create 失效的 workaround）：
   - 官方机型参数来源：`Emulator26.0/productConfig.json`（Pura X: 1320×2120@480, 外屏 980×980）与 `tools/emulator/emulator.json`；
   - 克隆 `deployed/PhoneAPI26` 的 config.ini/hardware-qemu.ini/huawei-settings.cfg/Camera.properties + lists.json 追加条目，type=widefold；
   - 首次启动可正常进系统并运行应用，但**稳定性待观察**（出现锁屏期间 guest 冻结 + 无快照可恢复导致的退出）；
   - 若持续不稳定：请用户在 DevEco Studio → Device Manager 正规创建 widefold 实例对照。
4. 模拟器息屏会锁屏且开发者模式不能自动解锁：启动应用前先 `devecocli ui swipe 660 1700 660 300` 解锁；连上 hdc 后立刻 `hdc shell power-shell timeout -o 2147483647` 保持常亮。
