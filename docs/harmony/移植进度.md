## 移植策略要点

1. **以 Android native 版为唯一移植基准**（不是 Web 版）——解析器回归测试绑定 Android 实现。
2. **解析器源码用 ArkTS 兼容的 TS 子集编写**（`entry/src/main/ets/importer/**/*.ts`），同一份文件：
   - 被 hvigor 编译进 HAP（.ets 通过相对路径 import）；
   - 被 Node 直接运行做回归测试（Node 24 原生 type stripping，无需 tsc）。
3. **持久化映射**（与 Android 的 SharedPreferences 大 JSON 不同）：
   - 题库/错题/收藏/记录 → `filesDir/misaka/state.json`（临时文件 + rename 原子写），规避 preferences 单值容量限制；
   - 轻量设置 → `@ohos.data.preferences`；
   - 图片 → `filesDir/question_assets/`（沿用 Android 同名目录，保 ZIP 备份互通）。
4. **AI 后置**：核心闭环（导入/练习/考试/错题/收藏/记录/备份）优先，AI 全家桶在 M8。
5. **阔折叠适配为 UI 主线**（用户要求）：所有页面按断点（sm/md/lg）自适应，展开态（1320×2120 内屏）优先设计宽屏侧边导航与双栏布局，跟随 Android 平板侧边导航模式；折叠/半开态回落单栏。折叠态切换需监听并保持页面状态。
6. 每个里程碑合并即 bump `AppScope/app.json5` 版本号 + CHANGELOG.md「HarmonyOS 版」段落 + 更新本文。

## v0.9.3 修复记录（2026-10-03，用户反馈：meTab 刷题偏好开关按了没反应）

「我的」tab 刷题偏好 7 个开关（选项打乱/斩题/快速编辑/滑动切题/自动提交/自动下一题/批量自动下一题）点击后 chip 一直显示「已关闭」。

- **根因**：开关值读 `repo.settings` 纯数据（非 @State），点击回调里 `bump()` 翻转 `tick` 想触发重建，但 meTab 渲染子树没有任何 `tick` 引用 → 无订阅者 → `SettingToggleRow` 的 `@Prop value` 永不重同步。设置值其实已写入 AppSettings 并 `putBool` 持久化（重启应用能看到新状态），纯视觉不刷新。全仓该模式共 6 处接点，其余 5 处（homeTab L319、practiceTab L497、WrongBookPage L201、AiSettingsPage L403、AppearancePage L193 都包 `if (this.tick % 2 === 0)` 奇偶换支重建，唯独 meTab 漏接。
- **修法**：刷题偏好 Column 提取为 `@Builder prefToggles()`，meTab 内 `if (tick % 2 === 0) prefToggles() else prefToggles()` 双支调用（复用本仓已验证模式）。
- **实测（WideFoldM4 展开态）**：选项打乱、斩题开关 chip「已关闭→已开启→已关闭」往返即时刷新（布局树 [2334,1510,2518,1590]），测试后还原默认关闭态；build 成功 + 七项 Node 自检全绿。

### 分层结构（Android 对应关系）

  - `AiSse.ts`：SSE 流式累积器——行缓冲跨块边界、`data:` 行提取、`[DONE]` 停止、delta `reasoning_content`+`content` 解析、onContent 传**累计全文**（Android 语义）、坏行静默跳过。
  - `AiCodec.ts`：配置校验与 **https-only** 端点规整（对齐 Android 明文拒绝）、HTTP 错误格式化（401/403/404/429/5xx 中文提示 + API error.message 提取截断 160）、非流式 choices 解析（空 choices/空内容友好报错）、六类 userPayload 构建（题库分析**按题号排序 200 题截断** + 题型统计 + note）、五类结果解析（核对建议 canApply/needHumanReview 默认规则 + hard_error 强制不可采纳；单题分析三态 matchesLocalAnswer + LOW 默认复核；AI 重构 clean_text/direct_questions 双模式含中文题型映射、多空 compatibilityAnswer、blankAnswers 每空去重取 3；题库分析链长≥2/实体出现≥2 过滤、空字段默认文案）。
  - `AiSuggestions.ts`：isActionable/canApply/merge 合并替换、缺解析判定（空/<20 字/「无」/「暂无解析」/简答无答案）、建议采纳应用（题型变更 + 选项替换 + 判断题 正确→A + 多选去重排序 + blankAnswers 清空）、练习页选项乱序映射（aiDisplayQuestionWithAnswer：选项按乱序展示序重排、displayKey 字母、答案与用户答案同步重映射——AI 看到的就是用户看到的，对齐 Android practiceQuestionForDisplay）。
